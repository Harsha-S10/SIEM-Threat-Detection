# 🛡️ SIEM Threat Detection

A centralized cybersecurity monitoring platform built using **Wazuh SIEM** and **Cowrie Honeypot** to detect, analyze, and respond to cyber threats in real time. The system collects security logs, monitors attacker behavior, generates alerts, and provides actionable insights through a centralized dashboard.

---

## 🎯 Objectives

- Centralize security log collection and analysis
- Monitor attacker behavior using a honeypot
- Detect suspicious activities in real time
- Generate alerts for security incidents
- Improve visibility into cyber attacks
- Support proactive threat detection and response

---

## ⚙️ Technologies Used

| Technology | Purpose |
|------------|----------|
| Wazuh SIEM | Log collection, monitoring, and alerting |
| Cowrie Honeypot | Captures attacker interactions |
| Filebeat | Log forwarding |
| Ubuntu Linux | Deployment environment |
| VirtualBox | Virtualized infrastructure |
| JSON Logs | Structured event storage |

---

## 🏗️ System Architecture

The framework consists of the following components:

1. Cowrie Honeypot captures attacker activities.
2. Security logs are generated and stored.
3. Filebeat forwards logs to Wazuh SIEM.
4. Wazuh analyzes events using custom rules.
5. Alerts are generated for suspicious activities.
6. Dashboard visualizes threats and system status.
