# SIEM Threat Detection

## Overview
A centralized cybersecurity monitoring platform built using Wazuh SIEM and Cowrie Honeypot to detect, analyze, and respond to cyber threats in real time.

## Technologies Used
- Wazuh SIEM
- Cowrie Honeypot
- Filebeat
- Ubuntu Linux
- VirtualBox

## Features
- Real-time log monitoring
- Threat detection and alerting
- Centralized security analysis
- Honeypot attack intelligence collection
- Security dashboard visualization
